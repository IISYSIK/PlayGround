## Vader: Shadow of the Empire

A standalone, keyboard- and touch-playable arcade game. Play as Darth Vader, clear three waves of rebel troopers, and survive the Death Star corridor.

### Play

Open `index.html` in a browser, or serve this folder locally:

```sh
python3 -m http.server 3002
```

Then visit `http://localhost:3002`.

### Controls

- **WASD / arrow keys** — move
- **Space** — swing the lightsaber and deflect blaster bolts
- **Q** — Force pull nearby enemies and clear incoming bolts
- On phones/tablets, use the on-screen movement, Force, and saber buttons.

No build step or external game dependencies are required.
